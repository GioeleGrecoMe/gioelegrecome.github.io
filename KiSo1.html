Come funziona

La modalità principale usa direttamente le API sperimentali WebXR Real World Geometry, seguendo il flusso degli esempi ufficiali immersive-web/webxr-samples.

MeshXRFrame.detectedMeshes: vertici, triangoli, meshSpace e aggiornamenti lastChangedTime.PianiXRFrame.detectedPlanes: poligoni planari già rilevati dal runtime AR.OutputPrima conserva la geometria metrica nativa; poi estrae grandi superfici verticali/orizzontali senza chiudere artificialmente la stanza.PrivacyNessun frame viene inviato a server. In questa versione non serve alcun modello AI.CompatibilitàRichiede un browser/device che esponga immersive-ar e almeno mesh-detection o plane-detection. Le API sono ancora sperimentali.
