ROOM SCANNER V11-D4 - INTERNAL TEST REPORT
Date: 2026-08-16

FINDING FIXED
- Diagnostic3 awaited the WebGPU probe before loading the original Depth worker.
- requestAdapter()/requestDevice() had no timeout.
- Therefore a GPU/driver stall could keep the app on the generic V10 "1/2" loading screen before the model was even requested.

D4 CHANGES
- WebGPU probe is non-blocking for worker bootstrap.
- requestAdapter timeout: 2500 ms.
- requestDevice timeout: 2200 ms.
- Original Depth worker fetch has a 15 s timeout and 1 s heartbeat.
- Model fetch has 1 s heartbeat with phase + received byte count.
- Session creation has 1.5 s heartbeat without changing InferenceSession semantics.
- Visible fixed build badge: ROOM SCANNER V11-D4 / DEPTH BOOT TRACE.
- Live trace is always visible at the top of the app.
- Worker progress is forwarded directly to the visible trace.
- Last D4 trace is persisted in localStorage so it can be recovered after page close/crash.
- V10 on disk, Service Worker, WebXR, camera/audio, geometry, fusion and thresholds are not modified.
